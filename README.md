# Drones Landing

Landing page para servicios audiovisuales con drones: presentación del servicio,
beneficios, portafolio visual y captación de clientes.

**Demo:** https://pagian-wed-de-drones.vercel.app

## Stack

HTML, CSS y JavaScript sin build ni dependencias.

## Local

Abre `index.html` en el navegador o sirve la carpeta:

```bash
python -m http.server 8080
```
